# Acervo Visual — catálogo editorial, não biblioteca de mídia pública

Este diretório contém apenas o **catálogo textual canônico em revisão**. As imagens originais não devem ser commitadas ao repositório sem revisão de direitos, autoria, licença e privacidade.

## Campos
Identificador estável, assunto, localização declarada, data, autor, licença, status de direitos e publicação, hash SHA-256, restrições e referência ao local de origem. Campos desconhecidos permanecem explicitamente desconhecidos.

## Fluxo de trabalho
1. Ingestão da fonte + preservação binária do original em armazenamento de mídia com controle de acesso.
2. SHA-256 e ID estável.
3. Checagem de autoria, contexto, data e direitos; revisão de conteúdo pessoal/sensível.
4. Somente após liberação editorial, criar derivados para parallax, tarja de crédito, versão pronta para Reel e transcrição de uso.
5. Registrar Reel/edição em que cada derivado entrou.
6. Revogação de direitos ou correção deve bloquear novas publicações sem apagar histórico de procedência.
